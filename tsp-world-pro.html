À propos du projet

TSP WORLD PRO est une application web interactive développée dans le cadre de notre Projet de Fin d'Études (PFE 2025-2026). Elle illustre la mise en pratique des concepts théoriques du Problème du Voyageur de Commerce (TSP), un problème fondamental d'optimisation combinatoire reconnu NP-difficile.

🎯 Objectifs du projet

L'objectif principal était de concevoir une plateforme complète permettant de :

  • Visualiser et comprendre l'explosion combinatoire du TSP
  • Implémenter plusieurs algorithmes de résolution (exacts, heuristiques, métaheuristiques)
  • Fournir une interface utilisateur intuitive avec carte interactive
  • Intégrer des fonctionnalités avancées (GPS, QR code, météo, export)
  • Démontrer l'application pratique des algorithmes d'optimisation

🏗️ Architecture technique

L'application repose sur une architecture frontale pure (HTML/CSS/JS) avec :

  • Leaflet.js : bibliothèque cartographique avec support de rotation 3D
  • OpenStreetMap & Nominatim : cartes et géocodage
  • OSRM (Open Source Routing Machine) : calcul d'itinéraires routiers
  • Open-Meteo : météo en temps réel
  • jsQR : décodage de QR codes
  • localStorage : persistance des données (villes, utilisateurs, rappels)

📊 Algorithmes implémentés

Notre application intègre deux algorithmes principaux pour le TSP :

  • Plus Proche Voisin (Nearest Neighbor) : heuristique gloutonne en O(n²) — solution rapide
  • 2-OPT : algorithme d'amélioration locale qui optimise la tournée initiale

Ces algorithmes sont combinés avec un routage réel via OSRM pour calculer les distances et temps de trajet entre les villes sélectionnées.

🔧 Fonctionnalités innovantes

  • Mode tilt 3D : vue immersive de la carte
  • Boussole interactive : orientation en temps réel
  • Points lumineux animés : visualisation dynamique des itinéraires
  • Partage de position par QR : génération et lecture de QR codes
  • Export Java : réutilisation des coordonnées dans d'autres projets
  • Popup style Google Maps : informations détaillées sur les lieux (météo, description, images)
